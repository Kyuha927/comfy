# Privacy policy

Effective date: 2026-09-14

Drive Reference Image Bridge is a skill-only package. It has no independent backend and does not collect, sell, retain, or transmit user data to a developer-operated service.

The workflow asks ChatGPT's connected Google Drive tool to read the exact image selected by the user and supplies that image to ChatGPT native image generation inside the same conversation. Google Drive and ChatGPT apply their own account, retention, and workspace policies.

The skill instructs the host not to change Drive sharing, not to log raw pixels, and not to reveal OAuth tokens or secret values. Diagnostic receipts contain only minimum file identity and integrity metadata and should omit private folder information.
