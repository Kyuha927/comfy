# ONE-SHOT WORK HANDOFF — AI / Game / Music / Video Technology Scouting

## Model routing
- MAIN portfolio owner: **GPT-5.6 Sol — Medium**
- Broad scouting/news/repository worker: **GPT-5.6 Luna — Medium**
- Benchmark/evidence verifier: **GPT-5.6 Terra — Medium**
- Adoption decision reviewer: **GPT-6 Astra — High; XHigh only for major stack-changing decisions**
- Integration planner for ACT NOW items: **GPT-5.6 Sol — High**
- Never use Pro in Work.

Own continuous technology scouting only for developments that can materially improve active systems: AI agents, game creation, Blender/3D, design, image/video/music generation, coding, model cost/performance, local/open models, and production automation.

Do not create a generic AI-news feed. For each finding ask: is it actually new, verified, materially better than something already in the stack, on what task, at what cost/limit, and worth integrating now?

Classify ACT NOW / TEST / WATCH / IGNORE. Prefer primary sources, technical reports, repositories, benchmark evidence, and real output comparisons over marketing repetition.

Luna scouts broadly. Terra verifies claims/benchmarks. Sol owns portfolio-level relevance and integration planning. Astra is reserved for consequential adoption decisions that could change architecture or expensive workflows.

Maintain a compact decision/change log to prevent repeated rediscovery. Only ACT NOW candidates should create implementation work.
