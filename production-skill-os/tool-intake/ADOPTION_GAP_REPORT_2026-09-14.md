# Adoption Gap Report — 2026-09-14

## Root design gaps found

1. **No executable global capability admission boundary.** Earlier reviews and isolated tests
   existed, but a consumer could still select a tool from prose without an exact registry query.
2. **Evidence levels were not bound to production scope.** Documentation, repository tests,
   isolated tests, and LIN same-path proof could be conflated.
3. **Version and authority drift were not blocked.** A mutable provider/tool or stale LIN SHA
   could be used without an exact mismatch failure.
4. **The generic character skill retained a stale P2 full-body hero-base bias.** Current LIN R04
   authority instead requires H3.1 component generation and controlled/manual reconstruction.
5. **Validation isolation was implicit rather than executable.** A candidate capability needed
   explicit no-production/no-canon constraints.
6. **Green CI could be overread.** CI proves guard and policy regressions, not 3D quality, provider
   output quality, scene state, fresh-process reopen, or rollback.
7. **Bridge capability and Bridge transport were not separated.** The packaged/offline core has
   bounded evidence, while the current live tunnel is blocked and the selected-R04 same-scene path
   has not run.
8. **Final user authority needed a machine-enforced invariant.** Every allow result now keeps
   canon promotion false and user final approval required.

## Corrections implemented

- one machine-readable registry with exact statuses, evidence, versions, constraints, failures,
  rollback, compatibility, and next gates;
- one fail-closed guard with explicit scopes and blocker codes;
- one consumer adapter used by the skill and CI;
- stale authority and version mismatch rejection;
- validation isolation flags;
- L8 same-path-only final authorization;
- R04 H3.1 component-route integration and P2 hero-route supersession;
- adversarial unit tests against fake promotion, stale SHA, wrong version, and omitted isolation;
- durable portfolio and handoff reports.

## Deliberately not closed

No real R04 component, current live Bridge transport, selected-component Blender scene, fresh-process
reopen, rollback, deformation, ART_MASTER, Mobile Hero, or real-device evidence was created by this
gate task. Those remain separate product evidence gates.
